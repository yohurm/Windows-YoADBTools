# Yovo ADB Tools — 架构设计 v4（重构蓝本）

> 定位：多模块 Windows 桌面工具平台。本文档是**全量重写**的实现蓝本，
> 基于四维度架构审查（平台/服务/MVVM/模型）+ 数据链路审查的结论重构。
> **不兼容旧代码**，保留经过验证的好设计，修正全部结构性问题。
> 原则：**简洁**（少类少层少约定）、**数据有归属**（每份数据一个属主）、**契约显式**（无隐式顺序/时序/字符串约定）。

---

## 1. 设计原则（审查结论 → 对策）

| 审查结论 | 对策 |
|---|---|
| 名义模块化（代码散落 5 目录） | 模块**物理收拢**：`Modules/AdbTerminal/{Models,Services,ViewModels,Views}` |
| 胖上下文（6 服务含模块服务） | 上下文只暴露 **4 个平台级服务**；模块服务模块内自持 |
| 编辑污染共享库（假"未保存"） | **快照编辑 + 全量提交**：编辑深拷贝，保存一次替换 |
| 判定策略下沉进程层 | AdbProcessService **纯进程**；判定上移 `CommandEvaluator` |
| 结果无归宿 | **ReportWriter**：执行结果结构化落盘 CSV |
| 标签逻辑矛盾 | 标签 = Category 派生，**删除独立标签管理** |
| 日志锁内写盘/全局广播 | 后台异步 flush + 按 Source 订阅过滤 |
| 模型无 INPC / 双轨绑定 | 模型全部 `ObservableObject`，XAML 全绑定 |
| 死代码（MesService/Settings 零消费/死转换器/死绑定） | 全部删除或接线 |
| 损坏覆盖/非原子写/无版本 | 单文件 `library.json`（version）+ 原子写 + 损坏备份 |
| DI 容器形同虚设 + 静态服务定位器 | **去 DI 容器**：平台 4 服务手工组装（简单直接），删除包依赖 |
| 占位模块埋雷/Id 硬编码 | 删除占位注册；模块 Id 单点常量 |
| 占位符静默错误/Dequeue 崩 | 模型级校验 + 结构化失败结果（不抛异常） |
| UI 集合穿透服务接口 | 服务暴露**不可变快照 + 事件**；UI 集合归 Shell 层 |

保留的好设计：统一 `CommandDefinition` 模型、单一数据源 + 事件驱动、执行引擎深拷贝防污染、
超时强杀进程树、设备刷新防重入、日志批量追加防卡死。

### 3.2 AdbProcessService — 纯进程调用

```csharp
public record AdbProcessResult(string Output, string Error, int ExitCode, long ElapsedMs);

public interface IAdbProcessService
{
    string AdbPath { get; }
    bool IsAvailable { get; }
    Task<AdbProcessResult> RunAsync(string serial, string command,
        int timeoutMs = 30000, CancellationToken ct = default);
}
```

- **零业务判定**：返回原始输出/退出码/耗时（判定归模块的 CommandEvaluator）
- 超时/取消语义区分：`RunAsync` 抛 `TimeoutException` / `OperationCanceledException`（调用方结构化处理）
- 保留：超时强杀进程树、CRLF 规范化、UTF-8 编码、嵌入式 ADB 解压（统一到 `%LOCALAPPDATA%\YovoAdbTools\adb\`）
- 参数：serial 用 `"-s " + QuoteArg(serial)` 转义，命令原样直传（注释说明）

### 3.3 DeviceService — 设备快照 + 会话

```csharp
public interface IDeviceService
{
    IReadOnlyList<AdbDevice> Devices { get; }          // 不可变快照
    IReadOnlyList<AdbDevice> SelectedDevices { get; }  // 不可变快照
    bool HasSelectedDevices { get; }
    event Action? DevicesChanged;      // 后台线程触发，订阅者负责 UI 编组
    event Action? SelectionChanged;
    Task RefreshAsync(CancellationToken ct = default); // 防重入
    void SetSelection(IReadOnlyCollection<AdbDevice> selected);
}
```

```csharp
public sealed record AdbDevice(string Serial, string State, string? Model)
{
    public bool IsOnline => State == "device";
    public string DisplayName => string.IsNullOrEmpty(Model) ? Serial : $"{Model} ({Serial})";
}
```

- `AdbDevice` 是**不可变 record** → 天然线程安全、无 INPC 问题（变化 = 替换 + 事件）
- `RefreshAsync`：一次 `devices -l` 调用**直接解析 model 字段**（`model:` 键），每设备仅 1 次进程调用；
  Android 版本移除（产线不需要，省 8 次进程调用）——需要时再按设备懒查
- **差异合并**：按 Serial 复用旧实例（Model 更新时替换），刷新不清空选中（serial 匹配保留）
- 内部 `SemaphoreSlim` 防重入；锁保护快照；事件在锁外触发

### 3.4 LogService — 后台写盘 + 按源过滤

```csharp
public enum LogLevel { Info, Warn, Error }
public sealed record LogEntry(DateTime Timestamp, LogLevel Level, string Message, string Source);

public interface ILogService
{
    void Info(string message, string source);
    void Warn(string message, string source);
    void Error(string message, string source);
    void Clear(string? source = null);          // 可按模块清空
    string LogFilePath { get; }
    event Action<LogEntry>? LogAdded;           // 订阅者按 Source 过滤
}
```

- 内存队列（上限 10 万条裁剪）+ **后台 flush 任务**（App 启动时创建，每 500ms 批量写盘，退出时 final flush）——锁内零 IO
- 文件轮转：单文件超 5MB → 滚动新文件（`app-YYYYMMDD-HHmmss.log`）
- `Clear(source)` 只清指定模块 → 终端面板清日志不再破坏平台全局
- 事件在后台线程触发；UI 侧由 VM 用捕获的 `SynchronizationContext` 编组

### 3.5 SettingsService — 原子写 + 异常保护

```csharp
public interface ISettingsService
{
    T Get<T>(string moduleId, string key, T defaultValue);
```

## 6. 数据链路设计（新走法对照）

| 链路 | 旧问题 | 新设计 |
|---|---|---|
| 配置 | 双文件/损坏覆盖/无版本/硬编码默认 | 单文件 library.json + version + 备份恢复 + 嵌入资源默认 |
| 配置→UI | 2N 事件风暴 | 保存一次 → 一次 LibraryChanged |
| 编辑 | 共享引用污染/假取消 | 深拷贝快照 + 全量提交（取消零污染） |
| 设备 | 16 进程/选中清零/无 INPC | 1 进程（解析 model）+ 差异合并 + record 快照 |
| 执行 | 隐式顺序契约/静默错命令/判定下沉 | 数量校验 + 结构化失败 + CommandEvaluator 上移 |
| 结果 | 无归宿/字符串化 | CommandResult 结构化 + CSV 落盘 |
| 日志 | 锁内 IO/全局广播/双管道 | 后台 flush + Source 过滤 + 单一管道（VM 集合） |
| 设置 | 死链路/无保护 | 原子写 + 异常保护 + 模块命名空间 |
