# ADR-v6-022 — 应用更新通道

- **状态：** 已接受（as-built）
- **日期：** 2026-08-28
- **修订：** 2026-09-01 — 仅 GitHub Releases；去掉更新源设置

## 决策

更新检查在 core crate `yohu-update`：固定查询 `yohurm/Windows-YoADBTools` 的 GitHub Releases。不引入 `tauri-plugin-updater`。设置页不提供更新源切换。

壳仅 `update.check` / `info` / `open`。仓库覆盖走环境变量或 `settings/update.json`。密钥不进 `settings.json` 主表，也不打进安装包。

`yohu-update` 可依赖 `yohu-protocol` 与 `yohu-runtime`（persist），**禁止**依赖 `yohu-adb` 与 Tauri。
