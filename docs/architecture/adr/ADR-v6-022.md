# ADR-v6-022 — 应用更新通道

- **状态：** 已接受（as-built）
- **日期：** 2026-08-28
- **修订：** 2026-09-01 — 仅 GitHub Releases；去掉更新源设置；应用内下载 NSIS 并 `/S` 覆盖安装

## 决策

更新检查与覆盖安装在 core crate `yohu-update`：固定查询 `yohurm/Windows-YoADBTools` 的 GitHub Releases。不引入 `tauri-plugin-updater`。设置页不提供更新源切换。

壳命令：`update.check` / `info` / `download` / `install` / `cancel` / `open`。进度事件 `update/progress`。仓库覆盖走环境变量或 `settings/update.json`。密钥不进 `settings.json` 主表，也不打进安装包。

覆盖安装：安装包下到 `%TEMP%\YohuAdbTools-update\`，助手等当前进程退出后静默 `/S` 写入 `%LOCALAPPDATA%\YohuAdbTools`，再拉起新主程序。设置/日志/数据不随安装包覆盖。

`yohu-update` 可依赖 `yohu-protocol` 与 `yohu-runtime`（persist / os_paths），**禁止**依赖 `yohu-adb` 与 Tauri。
