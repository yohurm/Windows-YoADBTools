# ADR-v6-022 — 应用更新通道

- **状态：** 已接受（as-built）
- **日期：** 2026-08-28

## 决策

更新检查在 core crate `yohu-update`：Provider 可替换；默认 GitCode；可选 GitHub / 蒲公英。不引入 `tauri-plugin-updater`。

壳仅 `update.check` / `info` / `open`。密钥不进 `settings.json` 主表：环境变量优先，否则 `settings/update.json`。

`yohu-update` 可依赖 `yohu-protocol` 与 `yohu-runtime`（persist），**禁止**依赖 `yohu-adb` 与 Tauri。
