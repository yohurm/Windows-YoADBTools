# ADR-v6-021 — 日志导出真相源

- **状态：** 开放（记录 as-built；本期不改实现）
- **日期：** 2026-08-28

## 背景

ADR-v6-006/007 与旧 §8.3 规定：导出/回补永远基于 RingBuffer。实现增加了 `SessionLogService`：UI 将**已过滤**行经 `log.sessionFileAppend` 落盘；`log.export` 合并这些文件。

## 现状

- replay / 镜像回补：仍读环（数据不丢推送）。
- 导出：读 `session-logs/`，不受 `buffer_capacity` 约束，可保留过滤后的完整会话。
- 追加为 fire-and-forget；失败只 `console.error`。溢出、崩溃、过滤变更会使导出与环分叉。
- 需求 §4.4 曾写设备日志仅用户导出时落盘；现在采集中持续写文件。

## 待决

A. 导出改回扫环（过滤在 core）。B. 把会话文件做成可靠管道并写清磁盘/隐私策略。未拍板前不继续加落盘选项。
