# ADR-v6-027 — 投屏占用：舞台透明洞 + HWND 占用卡片

- **状态：** 已接受
- **日期：** 2026-09-04
- **补充：** [ADR-v6-024](ADR-v6-024.md)、[ADR-v6-026](ADR-v6-026.md)

## 背景

声明栈：View → store → typed IPC → commands → shell present。

026 把舞台像素交给 HWND 之后，占用一度在 UI 算：`containInZone` 写出 hug 盒，YoPanel 铺满 hug 框，`mirror.layout` 报插值后的视觉盒。CSS 占用宽高过渡与 HWND 跟框锁步会左右跳。

随后两版都被实机否决：

1. **HWND 铺满整列舞台 YoPanel、画面只在 HWND 内 letterbox**：抖动消失，但左右边框是 YoPanel 外框，不再贴合画面。
2. **舞台 YoPanel 铺满列 + HWND 在面板内 contain**：avail 稳定，HWND 确实变窄，但用户看见的左右边框仍是 YoPanel，占用卡片看起来没变。

面板内全屏被做成 `position: fixed; inset: 0`。页眉被盖住。`SetFullscreenState` 非法。

## 决策

1. **View 只报稳定 avail。** 可用区 = 舞台列 `.yohu-mirror__avail`（透明洞，不是 YoPanel）。`mirror.layout` 报该格子相对主窗客户区的物理矩形 + 会话旗标。禁止报 contain 目标，禁止 `video_width` / `stroke_px`，禁止 CSS 占用宽高过渡。
2. **舞台不是 YoPanel。** 内容区只有操作栏 / 质量是 `YoPanel`。舞台列是布局槽：WebView 透明，露出 `--yohu-canvas`。可见占用卡片是 HWND。
3. **HWND 按画面 contain。** 会话中且 FramePipe 有编码尺寸 → `contain_in_zone(avail, encoder)`，左右边框贴合画面，两侧露出画布。idle / failed / unbound → 铺满 avail。编码尺寸只来自 FramePipe；`stop` 保留上次尺寸，下次 start 立刻 contain，禁止先铺满再收造成二次跳动。无编码尺寸时铺满。
4. **HWND 画占用铬层。** surface / hairline / radius 画在 HWND 上（空态与视频帧都描边）。画面填满 HWND（壳已 contain 后禁止 HWND 内再 letterbox，除非整数倍吸附）。
5. **面板内全屏是布局。** 只藏操作栏与功能栏。禁止 `position: fixed; inset: 0`。禁止 DXGI exclusive。禁止 HWND lerp、禁止运行时 UI `containInZone`、禁止 hide-on-jump 48px。

## 否决

WebView2 composition visual hosting、独立 scrcpy 窗、DXGI exclusive fullscreen、CSS 占用宽高过渡、HWND `SetTimer` lerp、UI 运行时 `containInZone`、`layout.video_width`、hide-on-jump、用舞台 YoPanel 当可见左右边框、把 HWND 永远铺满导致左右边框不再贴合画面。
