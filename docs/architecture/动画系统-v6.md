# YoUI 动画系统架构（v6）

> **状态：** 已落地（2026-08-20 M1–M5；传输卡双轨已清）  
> **范围：** `@yohu/ui` 动效单源 + 原语 + 配方；壳（侧栏）与模块只消费配方，禁止自写时长/曲线/`animation`。  
> **对照：** HarmonyOS 设计指南·动效（`harmonyos-design-notes.md` §5）；外部研究缓存 `temp/motion-research/`。  
> **ADR：** ADR-v6-017（本文 §12）。数值消费名仍走 `--yohu-dur-*` / `--yohu-ease-*`。

---

## 0. 结论

动效按六层落地，壳与模块只消费配方 class / `YoPresence` / `YoSwap` / `YoCollapse` / `YoIndicator`。禁止模块再写 `@keyframes` 或 `animation:`。

```
L0 原则（鸿蒙 PC · 效率型）
  → L1 Token（时长 / 曲线 / MotionSpec 语义槽）
    → L2 原语（transition · keyframes · Presence · Swap · Collapse · Indicator · reduced-motion）
      → L3 配方（rail / collapse / overlay / dialog / toast / fade / dismiss-fade / swap …）
        → L4 组件与壳接线（Yo* 与 AppLayout 只引用配方名）
          → L5 纪律（lint · 虚拟列表禁动 · 60fps · 可打断）
```

**实现选型：CSS-first，不引入 Framer / Fluent react-motion / GSAP。** Solid 只补四块 JS：`YoPresence`（出场结束再卸载）、`YoSwap`（沿轴裁切展开/收缩）、`YoCollapse`、`YoIndicator`（选中滑块）。侧栏等可逆布局走 CSS `transition`（天然可打断）。

## 2. 外部架构取舍

完整对照见 `temp/motion-research/synthesis.md`。一句话：

| 来源 | 借 | 不借 |
|------|----|------|
| HarmonyOS | 数值、原则、元素四类、PC=淡入淡出、时长随行程 | ArkUI API、弹簧默认、手机左右滑转场 |
| Material | spatial vs effects、语义 MotionSpec | 16 档 duration、Expressive spring |
| Fluent react-motion | Presence / one-shot / 并行轨道 / Fade·Collapse 配方 | React 包、WAAPI 作为唯一引擎 |
| Radix | `data-state` + 出场结束再卸 DOM | 无障碍原语与动画绑死（我们已有 ARIA） |
| Framer | 可打断布局过渡的概念 | 运行时、layout projection |

## 3. L0 原则（鸿蒙 PC · 效率型）

1. **过场义务**：相邻界面、侧栏开合、浮层开关禁止单帧直切。
2. **元素分类选曲线**：
   - 进场（新出现）→ 减速曲线 + 偏长时长
   - 出场（离开视线）→ 加速曲线 + 偏短时长
   - 持续（一直在视线，如侧栏变宽）→ 标准曲线
   - 选中滑块 / 开关 thumb → 位移 snap 弹簧；滑块宽高 soft 弹簧（拉伸回弹）
   - 静止 → 不动
3. **PC 层级 = 淡入淡出**。不要把手机「左右位移」套到模块切换。侧栏是**持续元素的宽度变化**，不是页面 push，用标准曲线做空间运动。
4. **行程定时长**：颜色 100；控件内 150；局部（一行/一折叠）200；面板级 300；大面板入场 350。上限 350ms。
5. **按下即反馈**：hover/active 颜色 ≤100ms，不得用 300ms 面板时长。
6. **空间 vs 效果**（Material，防鸿蒙弹簧误用）：
   - **effects**：color / opacity / box-shadow → 只允许贝塞尔，禁止过冲
   - **spatial**：侧栏 / 折叠 → 标准或强调减速；选中滑块位移允许 snap 弹簧，宽高允许 soft 弹簧；字色禁止弹簧
7. **可打断**：用户可逆操作（侧栏、折叠）必须用 `transition`，中途反向从当前值回去。一次性入场可用 `animation`。
8. **克制**：同一时刻尽量一条主运动；虚拟列表、日志流、进度数字不做装饰动画。
9. **降级**：`prefers-reduced-motion: reduce` 时配方时长 → 0（循环指示器除外，改为静态或降低对比的静止图形）。
10. **60fps**：优先 `transform`/`opacity`；布局属性（`grid-template-columns`、`grid-template-rows`）只允许用在 rail / collapse 两个配方。

## 4. L1 Token

### 4.1 时长（已有，不扩档）

继续用 HarmonyOS 分级，不抄 Material 的 16 档。

| Token | 值 | 行程 |
|-------|-----|------|
| `--yohu-dur-fast` | 100ms | 颜色 / 按下 |
| `--yohu-dur-small` | 150ms | 开关、指示器、chevron |
| `--yohu-dur-normal` | 160ms | 浮层淡入、小位移 |
| `--yohu-dur-local` | 200ms | 折叠、删除一行、浮层出场 |
| `--yohu-dur-slow` | 300ms | 侧栏、页面级 |
| `--yohu-dur-enter` | 350ms | Dialog 入场 |
| `--yohu-dur-progress` | 400ms | 进度最短感知 |
| `--yohu-dur-loop` / `loop-slow` / `toast` | 800ms / 1.2s / 3s | 循环与停留，不是过渡 |

### 4.2 曲线（补 accel / emphasized / 弹簧）

| Token | 值 | 场景 |
|-------|-----|------|
| `--yohu-ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 持续元素（鸿蒙标准）；侧栏 |
| `--yohu-ease-decel` | `cubic-bezier(0, 0, 0.4, 1)` | 进场（鸿蒙减速） |
| `--yohu-ease-accel` | `cubic-bezier(0.4, 0, 1, 1)` | 出场（配对减速） |
| `--yohu-ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | 折叠等局部空间，尾段更长 |
| `--yohu-ease-loop` | `ease-in-out` | 循环指示 |
| `--yohu-ease-spring` | snap 弹簧 `linear()` | 选中滑块位移、开关 thumb |
| `--yohu-ease-spring-soft` | soft 弹簧 `linear()` | 滑块宽高滞后（拉伸回弹） |

弹簧参数写入 `MotionSpring`。页面级仍是鸿蒙 128/12/1；**位移**用 snap（ζ≈0.75，约 4% 过冲），**尺寸**用更软的 soft。`spatialSmall` = 150ms spring；指示器位移按时长档压缩进行程（短跳 100 / 邻项 150 / 跨栏 200）：

```ts
export const MotionSpring = {
  stiffness: 128, damping: 12, mass: 1, velocity: 0,
  response: 0.555, dampingFraction: 0.53,
  snapStiffness: 711, snapDamping: 40,
  softStiffness: 531, softDamping: 29,
};
```

### 4.3 MotionSpec（语义槽，组件只引用这里）

组件禁止直接拼 `var(--yohu-dur-*)` + 一条曲线，除非配方表尚未覆盖的逃生口。新增：

```ts
export const MotionSpec = {
  effectsFast:     { duration: "fast",    easing: "standard" },   // hover/press 色
  effectsEnter:    { duration: "normal",  easing: "decel" },      // 淡入
  effectsExit:     { duration: "local",   easing: "accel" },      // 淡出，比入场短
  spatialSmall:    { duration: "small",   easing: "spring" },     // 开关/指示器位移
  spatialStretch:  { duration: "local",   easing: "springSoft" }, // 滑块宽高滞后
  spatialLocal:    { duration: "local",   easing: "emphasized" }, // 折叠高度
  spatialPanel:    { duration: "slow",    easing: "standard" },   // 侧栏宽度（不用弹簧）
  spatialEnter:    { duration: "enter",   easing: "decel" },      // Dialog 入场
  spatialExit:     { duration: "local",   easing: "accel" },      // Dialog/卡片出场
} as const;
```

CSS 对应发成成对变量，便于配方一次引用：

```css
--yohu-motion-effects-enter: var(--yohu-dur-normal) var(--yohu-ease-decel);
--yohu-motion-spatial-panel: var(--yohu-dur-slow) var(--yohu-ease-standard);
/* …每种 spec 一条 */
```

契约测试：`MotionSpec` 的 duration/easing 名必须存在于 `MotionDuration` / `MotionEasing`。

## 5. L2 原语

四类引擎，按「能不能打断、在不在树上」选型。

### 5.1 隐式过渡（CSS `transition`）

对应 ArkUI 属性动画、侧栏/开关/折叠。

- 属性已在树上，只改值。
- 可打断。
- 用于：`grid-template-columns`（rail）、`grid-template-rows`（collapse）、`transform`（滑块）、`background-color`。

折叠高度不用 JS 测 `scrollHeight`。标准手法：

```css
.yohu-collapse {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows var(--yohu-motion-spatial-local);
}
.yohu-collapse[data-open="true"] {
  grid-template-rows: 1fr;
}
.yohu-collapse__inner { overflow: hidden; min-height: 0; }
.yohu-collapse__inner > * { min-height: min-content; } /* 裁切，不把子项压扁 */
```

### 5.2 关键帧配方（CSS `@keyframes`）

对应 ArkUI 组件 transition 的视觉层。单源放 `tokens/motion.css`，组件 CSS 禁止再写 `@keyframes yohu-*`。

最低清单：

| 名称 | from → to | 默认 spec |
|------|-----------|-----------|
| `yohu-fade-in` / `yohu-fade-out` | opacity 0↔1 | effectsEnter / effectsExit |
| `yohu-rise-in` / `yohu-rise-out` | opacity + translateY(±8px) | spatialEnter 入 / spatialExit 出 |
| `yohu-slide-end-in` / `out` | opacity + translateX(±16px) | Toast（从右侧进，持续元素感弱、进场用 decel） |
| `yohu-scale-in` / `out` | opacity + scale(0.98↔1) | Dialog 面板 |
| `yohu-spin` | rotate 1turn | loop，linear |

位移距离走 spacing token（`--yohu-space-xs` / `sm` / `md`），禁止关键帧里写裸 `px`。

### 5.3 Presence（Solid，唯一必要的 JS）

对应 Fluent `createPresenceComponent`、Radix `forceMount`。

```ts
<YoPresence when={open()} recipe="dialog">
  {(state) => /* state: "enter" | "entered" | "exit" */}
</YoPresence>
```

行为：

1. `when` false→true：挂载，`data-state="open"`，播 enter。
2. `when` true→false：**不立刻卸载**，改 `data-state="closed"`，播 exit；`animationend`（或超时 = spec 时长 + 50ms）后再卸。
3. 中途再次打开：取消卸载，切回 `open`（可打断则用 transition；keyframes 则从当前帧 restart）。
4. `prefers-reduced-motion`：跳过等待，立即挂/卸。

Dialog / Toast / Select 菜单 / ContextMenu 全部改走 Presence，禁止裸 `<Show>`。

### 5.3.1 Swap（沿轴展开 / 收缩）

布尔 Presence 不能模拟「A 换成 B」。按钮文案走 `YoSwap`，**机制与侧栏/预览栏相同**（§9）：

- 槽位 `width` 从旧文案固有宽过渡到新文案固有宽（`spatialPanel`，标准曲线）。
- 内层锁固有宽、不换行；`overflow: hidden` 沿水平轴裁切。
- 默认锚在 **inline-end**（贴右往左收），与预览槽 `justify-content: flex-end`、窗口右缘一致。
- 变长：先换上新字再拉开（多出来的字从左缘露出来）。变短：先裁旧字，收完再换字。
- 禁止交叉淡入淡出，禁止在 `YoButton` 里测 `getBoundingClientRect`。

### 5.3.2 Indicator（选中滑块）

选中从 A 换到 B 不是进出场，是**持续元素**换位置。`YoIndicator` 是 track 内一块绝对定位滑块：

- 按选中项实测盒（或虚拟列表 `anchor`）设 `transform` + `width` / `height`（可打断）：位移走 snap 弹簧，时长按行程（`<32px` fast / `<128px` small / 否则 local）；宽高走 `spatialStretch`（200ms 软弹簧，形成拉伸）。仅 `follow` 变化时挂 `data-moving`；滚动/尺寸对位直切，避免弹簧拖尾。
- **过冲不得撑开滚动区**：fill 宿主 `overflow-x: hidden`（裁切宽过冲）。滑块宿主禁止 `overflow: auto`——Windows 会把另一轴也算成 auto，画出横竖条并互相锁死（同 Select v1.37）。设备栏：list 只裁切，纵滚走内层 scroller。
- `variant`：`thumb`（分段选择块）/ `underline`（Tabs 底边，只动 x+宽）/ `fill`（列表实底，圆角走 `--yohu-ripple-radius`）。
- 首帧量完再 `data-ready`，避免从 (0,0) 闪入。
- `fill` 时隐藏项上 `--selected::before`，避免双绘；字色与滑块同程过渡。多选（≥2）不要挂：退回每项 `::before`。
- **虚拟列表行级禁止**（不给每行挂 transition）；单选滑块可走 `YoIndicator` `anchor`。

### 5.4 状态契约（Radix 风格）

所有可开关表面统一：

```html
data-state="open" | "closed"
```

CSS：

```css
.yohu-dialog[data-state="open"]  .yohu-dialog__panel { animation: yohu-scale-in var(--yohu-motion-spatial-enter); }
.yohu-dialog[data-state="closed"] .yohu-dialog__panel { animation: yohu-scale-out var(--yohu-motion-spatial-exit); }
```

模块禁止自创 `is-open` / `--show` 类名。

### 5.5 reduced-motion

从「点名两个选择器」改为「配方统一降级」：

```css
@media (prefers-reduced-motion: reduce) {
  .yohu-motion-transition { transition-duration: 0.01ms !important; }
  .yohu-motion-enter,
  .yohu-motion-exit { animation: none !important; }
  /* loop 指示器保留，但可改为静态；见配方 spin */
}
```

JS：`prefersReducedMotion(): Accessor<boolean>`，Presence 与测试用。

## 6. L3 配方目录

配方 = 命名好的「属性 × spec × 原语」。组件只写 `recipe="rail"` 或 class `yohu-recipe-rail`。

| 配方 | 原语 | spec | 属性 | 使用方 |
|------|------|------|------|--------|
| `color` | transition | effectsFast | color, background, border-color | Button, Checkbox, TextField, IconButton |
| `switch` | transition | spatialSmall | transform（轨色仍 effectsFast） | YoSwitch |
| `indicator` | transition | spatialSmall 位移 + spatialStretch 宽高 | transform, width, height | `YoIndicator`：SegmentedButton、Tabs 下划线、单选列表实底 |
| `overlay` | presence + fade | enter effectsEnter / exit effectsExit | opacity | Dialog 遮罩 |
| `dialog` | presence + scale | enter spatialEnter / exit spatialExit | opacity, translateY, scale | YoDialog 面板 |
| `toast` | presence + slide-end | enter effectsEnter / exit effectsExit | opacity, translateX | YoToast |
| `popover` | presence + rise/drop | enter effectsEnter / exit effectsExit | opacity, translateY(±8) | YoSelect 菜单（下 rise / 上 drop）、YoContextMenu |
| `rail` | transition | spatialPanel | grid-template-columns | AppLayout 侧栏、文件预览栏 |
| `collapse` | transition | spatialLocal | grid-template-rows 0fr/1fr | DeviceRail 列表、终端结果卡、Tree 子树 |
| `tree-chevron` | transition | spatialSmall | transform rotate | YoTree 箭头（行本身仍禁背景过渡） |
| `tree-children` | collapse | spatialLocal | 子树高度 | YoTree 子节点；节点 >8 个时不做 stagger |
| `module-fade` | presence + fade | effectsEnter / effectsExit | opacity | 壳模块切换（PC 层级转场） |
| `dismiss-fade` | animation forwards + delay | 停留 `toast` − `slow` 后 spatialPanel 淡出 | opacity | 传输终态；store 于 `DISMISS_HOLD_DURATION` 移除。模块禁止再写一套 |
| `swap` | 槽宽过渡 + 沿轴裁切 | `spatialPanel`（与 rail 同） | width | 按钮文案。内层锁固有宽，默认贴 inline-end |
| `progress` | transition | progress 400ms + standard | width | YoProgressBar 确定态 |
| `spin` | animation infinite | loop + linear | rotate | YoIconButton loading |
| `list-insert` / `list-remove` | presence + rise | spatialLocal | opacity, height | **非虚拟**短列表；VirtualList **禁用** |

并行轨道（Fluent grouped motions，CSS 多 animation-name）：

- Dialog 打开：遮罩 `overlay` 160ms 与面板 `dialog` 350ms **同时起步**，不要等遮罩结束再出面板。
- Toast：单轨道即可（条目少，不做 stagger）。

## 9. 关键场景：侧栏展开 / 收回

这是用户点名的第一条产品动画，也是「持续元素 + 空间运动」的样板。

### 9.1 为什么不是滑入页面

鸿蒙：电脑层级转场用淡入淡出；侧栏在效率型应用里是**常驻导航**，收回只是把持续元素宽度收到 0，物体始终在「布局语义」里。用 **标准曲线 300ms**（`spatialPanel`），不要用减速入场也不要左右 push。

### 9.2 DOM 策略

当前实现已经把 rail 留在 DOM 里，只加 `.yohu-layout--rail-collapsed`——这是对的（若改成 `<Show>` 会无法做宽度过渡）。

**裁切沿收缩轴，禁止回流改写内容高度。** 列宽从 `shell-nav` 收到 `0` 时，若内层跟着变窄，文字会换行、卡片被压高，视觉上像「内容被向下挤」。必须把内容锁在展开宽度，由 `overflow: hidden` 从右侧裁掉：

```css
.yohu-layout {
  display: grid;
  grid-template-columns: var(--yohu-layout-shell-nav) minmax(0, 1fr);
  transition: grid-template-columns var(--yohu-motion-spatial-panel);
}
.yohu-layout--rail-collapsed {
  grid-template-columns: 0 minmax(0, 1fr);
}
.yohu-layout__rail {
  overflow: hidden; /* 收进过程裁切内容，不要用 visibility:hidden 抢在过渡前 */
  min-width: 0;
}
.yohu-layout__rail-inner {
  width: var(--yohu-layout-shell-nav);
  min-width: var(--yohu-layout-shell-nav);
  height: 100%;
}
```

收回期间 **不要**立刻 `visibility: hidden` / `pointer-events: none` 叠在同一帧——`pointer-events: none` 可以立刻加（防误点），`visibility` 等到 `transitionend` 或忽略（overflow:hidden + 宽度 0 已不可点）。收起后给 `<aside>` 加 `inert`，避免被裁切的控件仍进 Tab 序。

标题栏侧栏按钮保持可点，状态用 `aria-expanded`。

### 9.3 内容区

主列 `minmax(0,1fr)` 跟着变宽，这是持续元素，同一条 `grid-template-columns` 过渡即可，不要再给 `main` 做淡入。

### 9.4 reduced-motion

时长 0.01ms，列宽仍切到目标，布局不错位。

### 9.5 设备列表折叠

侧栏内部 DeviceRail 是**局部折叠**，用 `collapse`（200ms），不要复用 300ms 的 `rail`（行程更小）。Tree 子节点同配方。

| 项 | 决策 |
