# 命令管理模块 — 架构设计

## 1. 目标

统一管理**单条命令**与**命令组**的增删改查（CRUD），命令组支持细粒度步骤配置（延时、超时、失败策略），并预置 Nori 产测流程命令组。

## 2. 数据模型

### 2.1 单条命令 `AdbCommand`

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | string | 唯一标识 |
| Name | string | 显示名称 |
| Category | string? | 分类（通用 / Nori产测 / 自定义） |
| Command | string | ADB 命令，支持 `{0}` `{1}` 占位符 |
| InputPrompts | List\<string\> | 输入提示列表（对应占位符） |
| TimeoutMs | int | 超时（毫秒），默认 30000 |

### 2.2 命令组 `CommandGroup`

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | string | 唯一标识 |
| Name | string | 组名称（如"写入SN"） |
| Description | string? | 描述 |
| Steps | List\<GroupStep\> | 有序步骤列表 |

### 2.3 步骤 `GroupStep`

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| Command | string | "" | ADB 命令，支持 `{0}` 占位符 |
| Description | string? | null | 步骤说明 |
| DelayAfterMs | int | **500** | 本步执行后延时（毫秒） |
| TimeoutMs | int | 30000 | 本步超时（毫秒） |
| StopOnFail | bool | **true** | 失败是否中断（默认中断） |
| InputPrompts | List\<string\> | [] | 输入提示（对应 `{0}`） |

## 3. 统一参数输入机制

### 3.1 架构

输入区为**主界面右侧独立列**（第三列，280px），由 ViewModel 的 `ActiveInputs` 集合统一驱动：

```
选中单条命令 → ActiveInputs = 该命令的 InputPrompts 输入框
选中命令组   → ActiveInputs = 组内所有需要输入步骤的输入框（带"步骤N: 描述"标题）
无需输入     → 输入列自动隐藏（HasInputPanel = false）
```

- 数据模型：`InputField { GroupLabel?, Label, Value }`（命令与命令组共用）
- 执行时直接从 `ActiveInputs` 读取值，无弹窗
- 输入框值在切换选中对象时清空重建（产线场景：选命令 → 填值 → 执行）

### 3.2 执行引擎规则

```
执行命令组(serial, group):
  for step in group.Steps:
    若 step 需要输入 → 从 ActiveInputs 按顺序取值替换 {0}
    执行 adb 命令（超时 step.TimeoutMs）
    记录结果
    若失败且 step.StopOnFail == true → 中断，标记 Aborted
    否则延时 step.DelayAfterMs
  返回 (Results, Aborted)
```

- 输入校验：执行前检查所有输入框非空，空值提示并中止
- 失败中断后，日志显示"在第 N 步中断"

## 4. 界面设计

### 4.1 命令管理窗口（统一 CRUD）

```
┌─ 命令库管理 ────────────────────────────────────┐
│ [单条命令] [命令组]                              │
├─────────────────────────────────────────────────┤
│ 单条命令页:                                      │
│   左侧: 命令列表           右侧: 名称/分类/命令/  │
│         [新增][删除]             超时/输入提示/描述│
│                                  [保存]          │
├─────────────────────────────────────────────────┤
│ 命令组页:                                        │
│   左侧: 命令组列表           右侧: 组名称/描述    │
│         [新增][删除]             步骤表格:        │
│                                 # 描述 命令 延时  │
│                                   超时 中断 输入  │
│                                 [新增步骤][删除]  │
│                                 [上移][下移][保存]│
└─────────────────────────────────────────────────┘
```

### 4.2 步骤表格列

| 列 | 编辑方式 |
|----|---------|
| 描述 | DataGrid 文本列 |
| 命令 | DataGrid 文本列 |
| 延时(ms) | DataGrid 数字列，默认 500 |
| 超时(ms) | DataGrid 数字列 |
| 失败中断 | DataGrid CheckBox 列，默认勾选 |
| 输入提示 | DataGrid 文本列（逗号分隔，对应 {0} {1}） |

### 4.3 执行时输入收集对话框

- 标题：命令组名
- 对每个需要输入的步骤：显示"步骤 N: 描述/命令" + 输入框（提示文本）
- 校验非空，取消则中止整个命令组

## 5. 预置 Nori 命令组 — "写入SN"

| 步骤 | 命令 | 延时 | 超时 | 失败中断 | 输入 |
|------|------|------|------|---------|------|
| 1. 检查设备 | `get-state` | 500 | 10000 | 是 | 无 |
| 2. 进入产测模式 | `shell bdft write -testmode B` | 1000 | 60000 | 是 | 无 |
| 3. 写入SN | `shell bdft write -sn {0}` | 500 | 60000 | 是 | 请输入SN |
| 4. 查询SN | `shell bdft read -sn` | 500 | 30000 | 是 | 无 |

## 6. 模块划分

```
Models/
  AdbCommand.cs          # 单条命令（已有，不变）
  GroupStep.cs           # 步骤（扩展: DelayAfterMs=500, StopOnFail, InputPrompts）
  CommandGroup.cs        # 命令组（已有，不变）
  AdbCommandEditable.cs  # 单条命令编辑模型（已有）
  CommandGroupEditable.cs# 命令组编辑模型（新增）
  GroupStepEditable.cs   # 步骤编辑模型（新增）

Services/
  AdbService.cs          # ExecuteGroupAsync 支持 StopOnFail 策略
  ConfigService.cs       # 预置"写入SN"命令组；Load/Save 命令组

Views/
  CommandManagerWindow.xaml    # 统一管理窗口（改造为双 Tab）
  MultiStepInputDialog.xaml    # 多步骤输入收集对话框（新增）

ViewModels/
  MainViewModel.cs       # 执行命令组前收集输入；管理窗口保存后刷新命令组
```

## 7. 兼容性

- 旧版 commands.json / groups.json 反序列化：新增字段取默认值（DelayAfterMs=500, StopOnFail=true），无需迁移
- 命令组步骤的 InputPrompts 为空时，不弹输入框，行为与旧版一致
