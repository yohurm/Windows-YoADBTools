# Yovo ADB Tools — 需求分析

> 本文档随架构 v5 模块化单体重构同步更新（2026-08-11）。架构细节见 `docs/architecture/架构设计-v5.md`。

## 1. 项目概述

**项目名称：** Yovo-Windows-ADBTools（Yovo ADB Tools）
**目标平台：** Windows 10/11（x64）
**核心定位：** 多模块 Windows 桌面工具平台（Yovo ADB Tools），基于 ADB 提供设备调试与产测工具集，降低产线测试人员对命令行 ADB 的依赖。ADB 命令终端为当前首个模块，平台支持模块插拔扩展（投屏显示等）。

---

## 2. 核心需求

### 2.1 内置 ADB 工具

- 应用程序内置 ADB 二进制（adb.exe + AdbWinApi.dll + AdbWinUsbApi.dll，嵌入资源打包进单 exe）
- 优先使用应用目录 `tools/adb.exe`（开发调试）；发布版从嵌入资源解压到 `DataRoot\tools\adb\`（默认 `%LOCALAPPDATA%\YovoAdbTools\data\tools\adb\`）
- 无需用户额外安装 Android SDK / Platform Tools，无需管理员权限

### 2.2 命令发送机制

| 场景 | 说明 |
|------|------|
| **单条命令** | 用户从预设列表中选择一条 ADB 命令，点击发送（多设备并行） |
| **命令组** | 一组有序命令依次执行，支持步骤延时/失败中断策略（如：重启 → 等待 → 检查状态） |
| **规则/功能** | 预留（架构支持，尚未实现） |

### 2.3 成功判定策略

产测工具（bdft）退出码不可靠（成功返回 255、参数错误返回 0），判定优先级：
1. 输出匹配 **失败正则** → 失败（最高优先）
2. 输出匹配 **成功正则** → 成功
3. 退出码为 0 → 成功

### 2.4 用户界面

- 简洁、清晰，适配产线操作人员使用（浅色主题）
- 左侧平台公共区：设备列表（型号 + 序列号 + 在线状态点）+ 模块导航
- 命令分类展示（通用 / Nori产测，可编辑）
- 执行日志实时显示（按级别着色，来源按模块过滤）
- 执行状态指示（进度条 + 状态文本）

### 2.5 轻量化

- 单 exe 打包（自包含，约 75MB 含 ADB）
- 低资源占用，可在老旧 Windows 产线工控机上运行
- 无需额外运行时

## 3. 功能模块

### 3.1 设备管理
- 扫描并列出已连接的 ADB 设备（一次 `devices -l` 进程调用，解析型号）
- 显示设备状态（device / unauthorized / offline）、型号、序列号
- **手动刷新**（启动自动扫描一次；产线插拔后手动点刷新）
- 多选设备，命令并行发送

### 3.2 命令管理
- 预设命令库（JSON 配置驱动，管理窗口可编辑、可扩展）
- 命令分类（通用 / Nori产测）；分类即标签（纯派生，无独立标签管理）
- 单条命令与命令组步骤统一模型（占位符 {0} {1} + 输入提示）
- 配置校验：名称非空、占位符与输入提示数量一致、正则合法

### 3.3 执行引擎
- 单条命令执行（多设备并行）
- 命令组顺序执行（步骤级实时日志、失败中断策略、步骤延时）
- 超时控制（可配置，超时强杀进程树）
- 成功判定策略（见 2.3）
- 结构化结果（成功/失败 + 判定来源 + 耗时 + 输出）

### 3.4 测试结果
- **不落盘**：执行结果仅在日志面板实时显示（结构化：设备/命令/判定/耗时），不生成报告文件

### 3.5 配置管理
- 单文件 `{数据目录}/Config/library.json`（commands + groups + version）
- 内置默认命令库随应用分发（嵌入资源，首次启动生成）
- 损坏文件自动备份（`.bak-时间戳`）后恢复内置，绝不静默覆盖用户数据
- 原子写入（临时文件 + 替换）

### 3.6 日志
- 平台级日志：**仅内存 + 界面实时显示**（不写文件），按模块 Source 过滤，上限裁剪防无限增长

### 3.7 设置面板
- 平台面板（导航"设置"进入右侧操作面板，非弹窗）
- **ADB 路径**：可指定 exe 或目录；留空自动解析（应用目录 Tools → 内置解压）；保存立即生效
- **数据目录**：命令库/ADB 解压等全部文件位置；留空默认 `%LOCALAPPDATA%\YovoAdbTools`；保存重启生效
- 设置存储：`%LOCALAPPDATA%\YovoAdbTools\Settings\app.json`（原子写 + 损坏回退）

## 4. 技术选型

| 层次 | 技术 | 理由 |
|------|------|------|
| 语言/框架 | **C# / WPF (.NET 8)** | 原生 Windows 体验 |
| MVVM | CommunityToolkit.Mvvm（源生成器） | 简洁、INPC 全自动 |
| UI | WPF-UI (Fluent) + ThemeTokens 统一资源 | 现代 Fluent 外观，浅色主题 |
| ADB 集成 | 内嵌 adb.exe 嵌入资源 | 运行时解压，进程启动调用 |
| 打包 | **.NET 自包含单文件发布** | `dotnet publish -p:PublishSingleFile=true` |
| 配置存储 | JSON（单文件 + 版本 + 备份） | 轻量、可读、可编辑 |
| 日志 | 界面实时显示（内存，不落盘） | 产线问题即时可见 |

> 备选：Python + PyInstaller 打包，但体积较大且需额外打包运行时，不推荐。

## 5. 已确认决策

| 决策项 | 结论 |
|--------|------|
| UI 框架 | **WPF (.NET 8)** |
| 多设备并行 | **支持**，可多选设备发送命令 |
| MES 对接 | **预留接口**，暂不实现（MesService 已移除，对接时再实现） |
| UI 语言 | **中文** |
| 配置格式 | **JSON**（单文件 library.json + version） |
| 成功判定 | **失败正则 → 成功正则 → 退出码** 三级策略 |
| 测试结果 | **不落盘**（日志面板实时显示） |
| 日志 | **仅内存 + 界面**，不写文件 |
| 标签 | **纯派生**（分类去重），无独立标签管理 |
| 设置面板 | **右侧操作面板**（导航进入，非弹窗）；ADB 路径立即生效、数据目录重启生效 |
| 设备刷新 | **手动刷新**（+ 启动扫描），不做后台轮询 |
| 模块化 | **单程序集 + 模块目录收拢**，IModule 契约插拔 |

## 7. 约束条件

- 目标 OS：Windows 10 / 11（x64）
- 运行时：.NET 8（自包含发布时无需预装运行时）
- 产线工控机可能无管理员权限：所有写路径均在 `%LOCALAPPDATA%\YovoAdbTools\` 与应用目录 `Config\`，不写注册表/系统目录
- 产测设备和 PC 之间通过 USB 连接
