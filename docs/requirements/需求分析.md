> **版本：** 与 v5 实现同步（2026-08-11）  
> **架构：** `docs/architecture/架构设计-v5.md`

## 1. 项目概述

| 项 | 内容 |
|----|------|
| 名称 | Yovo-Windows-ADBTools（Yovo ADB Tools） |
| 平台 | Windows 10/11（x64） |
| 定位 | **设备工具工作台**：基于 ADB 的产测/调试多模块桌面平台 |
| 当前模块 | ADB 命令终端、文件管理、日志分析；投屏显示仅导航占位 |

## 3. 平台能力（已实现）

### 3.1 工作台壳（Shell）

- 左侧：**设备栏**（型号/序列号/在线状态）+ **模块导航**
- 右侧：**单一内容区**（当前模块主视图）
- 底部/状态：后台任务登记（如 logcat 采集、文件传输）
- 导航项来自模块贡献点；`screen-mirror` 为 Planned「开发中」占位
- 设置：导航进入右侧面板（非弹窗）

### 3.2 设备管理

- `adb devices -l` 扫描；显示 device / unauthorized / offline
- **手动刷新** + 启动预热扫描一次（不做默认后台轮询）
- **设备目录**与**选择会话**分离：全局焦点 ActiveDevice + 每模块选择作用域
- 终端：`MultiOptional`（多选并行）；文件/日志：`SingleRequired`（跟全局焦点）
- 焦点设备掉线/切换：日志分析自动停采

### 3.3 内置 ADB / 工具链

- 解析顺序：用户设置 → 应用旁 `tools/` → 嵌入资源解压到 `DataRoot/tools/adb/`
- 进程能力：短命令 / 流式 / 长驻（长驻为远期投屏预留）
- 传输：push/pull + 进度；取消 Kill 进程树
- ADB 路径设置**立即生效**；数据目录**重启生效**（启动冻结快照）

### 3.4 应用日志 vs 设备日志

| 类型 | 用途 | 落盘 |
|------|------|------|
| `IAppLog` | 应用/模块操作日志 | 默认仅内存 + UI |
| 日志分析模块 | 设备 `logcat` | 环形缓冲；导出到模块目录 |

二者严格分离（ADR-006）。

### 3.5 设置（必要项）

| 键 | Scope | 生效 | 说明 |
|----|-------|------|------|
| `adb.path` | app | 立即 | 空 = 自动解析 |
| `data.root` | app | 重启 | 默认 `%LOCALAPPDATA%\YovoAdbTools\data` |
| `buffer.capacity` | log-analyzer | 下次采集 | 环形缓冲行数，默认 50000 |
| `display.limit` | log-analyzer | 重启模块/进程 | 界面可见行上限，默认 2000 |
| `clear.device.on.start` | log-analyzer | 下次采集 | 开始前 `adb logcat -c` |

设置文件根固定：`%LOCALAPPDATA%\YovoAdbTools\settings\`（不随数据目录迁移）。

## 4. 功能模块需求

### 4.1 ADB 命令终端（已实现）

- 预设命令库 / 命令组；分类 = 标签（纯派生）
- 占位符 `{0}` `{1}` + 输入提示；校验名称/占位符/正则
- 多设备并行；组内顺序、延时、失败中断
- 成功判定：**失败正则 → 成功正则 → 退出码**
- 管理窗口：深拷贝编辑、全量保存、取消零污染
- 数据：`DataRoot/modules/adb-terminal/config/library.json`；损坏备份；支持 v4 路径迁移
- 结果：结构化展示于模块日志区，**测试结果不落盘**

### 4.2 文件管理（已实现 MVP）

- 浏览目录；上传/下载（进度 + 可取消）；删除/新建目录
- 危险删除：安全根严格子路径（`/sdcard`、`/storage` 子路径）；用户确认
- 路径规范化，拒绝 `..` 穿越
- 后台任务登记传输

### 4.3 日志分析（重点演进）

**已实现：**

- 流式 `adb logcat -v threadtime`；环形缓冲；虚拟化列表；级别着色
- 过滤：最低级别（含以上，对齐 Android Studio）、Tag 包含、**关键字包含**（**无正则框**）
- 开始/停止/暂停（暂停仅冻 UI，缓冲继续）/清空界面与缓冲/导出过滤结果为 txt
- 可选：开始前清空设备缓冲；后台任务；退出停采
- 单设备（全局焦点）；掉线/切换停采

**目标能力清单（见架构文档，分 P0/P1/P2 排期）** 摘要：

- 软换行、自动滚底/解除、清空设备缓冲按钮、复制行、级别含以上（已做）
- 关键字高亮、PID/包名过滤、崩溃/异常信号提示、过滤预设
- 远期：查询语法、书签、多缓冲（main/crash/radio）、性能对齐时间轴等 — **非本期**

### 4.4 投屏显示

- **仅 Planned 占位**，本期不实现（ADR-007）

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 性能 | 工控机可用；logcat UI 节流 + 虚拟化；避免全量同步绑定 |

| 主题 | 浅色 Fluent（WPF-UI + ThemeTokens） |

## 7. 已确认决策

| 决策 | 结论 |
|------|------|
| 模块化 | 多项目模块化单体；模块互不引用实现 |
| 设备模型 | Directory + SessionHub；按模块选择模式 |
| 应用日志 | 默认不落盘 |
| 设备 logcat | 模块自持；可导出 |
| 投屏 | 仅占位 |
| MES | 预留，暂不实现 |
| 日志过滤 | 级别 + Tag + 关键字；**不做正则输入框** |
| 设置页 | 仅必要项（工具链 + 日志运行参数） |

## 9. 约束

- OS：Windows 10/11 x64  
- 无管理员权限；数据在 LocalAppData  
- 设备通常 USB ADB 连接  
- 单进程单 exe，不引入插件热加载
