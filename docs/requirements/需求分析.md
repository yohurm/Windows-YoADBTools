## 1. 项目概述

| 项 | 内容 |
|----|------|
| 名称 | Yovo-Windows-ADBTools（Yovo ADB Tools） |
| 平台 | Windows 10/11（x64） |
| 定位 | **设备工具工作台**：基于 ADB 的产测/调试多模块桌面平台 |

## 4. 平台能力

### 4.1 工作台壳（Shell）

- 左侧：**设备栏**（型号/序列号/在线状态，可折叠）+ **模块导航**
- 右侧：**单一内容区**（当前模块主视图）
- 底部：**状态栏**（后台任务登记 + 设备状态 + 版本号）
- 导航项来自模块贡献点；`screen-mirror` 为 Planned「开发中」占位
- 设置：导航进入右侧面板（非弹窗）

### 4.2 设备管理

- `adb devices -l` 扫描；显示 device / unauthorized / offline
- **手动刷新** + 启动预热扫描一次 + 可选自动刷新（设置项 `devices.autoRefresh`，秒，默认 0=关）
- **设备目录**与**选择会话**分离：全局焦点 ActiveDevice + 每模块选择作用域
- 终端：`MultiOptional`（多选并行）；文件/日志：`SingleRequired`（跟全局焦点）
- 焦点设备掉线/切换：日志分析自动停采（该设备全部会话）

### 4.3 ADB 工具链（sidecar）

- 打包：官方 adb.exe + AdbWinApi.dll + AdbWinUsbApi.dll 作为 **Tauri sidecar** 随安装包分发，运行时解压到 `DataRoot/tools/adb/`
- 解析顺序：用户设置（`adb.path`）→ 应用旁 `tools/` → 内置解压
- 进程能力：短命令 / 流式 / 长驻（长驻为远期投屏预留）
- 明确**不重实现 ADB 协议**（Rust crate 生态不成熟，ADR-v6-008）
- ADB 路径设置**立即生效**；数据目录**重启生效**（启动冻结快照）

### 4.4 应用日志 vs 设备日志（严格分离）

| 类型 | 用途 | 落盘 |
|------|------|------|
| 应用日志 | 应用/模块操作日志（内存环形 + UI 展示） | 默认不落盘；崩溃 panic 日志单独写 `logs/` |
| 日志分析模块 | 设备 `logcat`（core 环形缓冲） | 仅按用户操作导出 txt |

### 4.5 设置（必要项）

| 键 | Scope | 生效 | 默认 | 说明 |
|----|-------|------|------|------|
| `adb.path` | app | 立即 | 空 | 空 = 自动解析 |
| `data.root` | app | 重启 | `%LOCALAPPDATA%\YovoAdbTools\data` | 数据目录 |
| `devices.autoRefresh` | app | 重启 | 0（关） | 自动刷新间隔秒数 |
| `buffer.capacity` | log-analyzer | 下次采集 | 50000 | 设备共享环形缓冲行数 |
| `display.limit` | log-analyzer | 立即（重建可见区） | 2000 | 每会话可见行上限 |
| `clear.device.on.start` | log-analyzer | 下次采集 | true | 开始前 `adb logcat -c` |
| `theme` | app | 立即 | light | 主题（light/dark，组件库 token 层支持） |

设置文件根固定：`%LOCALAPPDATA%\YovoAdbTools\settings\`（不随数据目录迁移）。

## 5. 功能模块需求

### 5.1 ADB 命令终端

- 预设命令库 / 命令组；分类 = 标签（纯派生）
- 占位符 `{0}` `{1}` + 输入提示；校验名称/占位符/正则
- 多设备并行；组内顺序、延时、失败中断（编排在 core 领域层，可单测）
- 成功判定：**失败正则 → 成功正则 → 退出码**（判定在 core 领域层，客户端不判定）
- 管理窗口：深拷贝编辑、保存全量提交、取消零污染
- 数据：`DataRoot/modules/adb-terminal/config/library.json`；损坏备份；**支持 v5 数据一次性迁移**（数据迁移 ≠ 设计兼容）
- 结果：结构化展示于模块日志区，测试结果不落盘

### 5.2 文件管理

- 浏览目录（ls 解析）；上传/下载（进度 + 可取消）；删除/新建目录
- 危险删除：安全根严格子路径（`/sdcard`、`/storage` 子路径）+ 用户确认；**core 侧强制校验**（不信任 UI 传来的路径）
- 路径规范化，拒绝 `..` 穿越
- 后台任务登记传输

### 5.3 日志分析（基线能力）

**基线（第一期交付即含）：**

- 流式 `adb logcat -v threadtime`（core 单流采集）；设备级共享环形缓冲
- **多会话 Tab（Xshell 式）**：按 **包名 / PID / 全部** 三种 Scope 划分；进程索引（`ps` 周期刷新）+ 包名 PID 自动重绑（含历史 PID 集）
- AS 风格过滤栏：级别（含以上）/ 包名（含子进程开关）/ 精确 PID / Tag / 关键字检索；**无正则框**
- 每会话独立：暂停（冻 UI 缓冲继续）/ 自动滚底 / 信号计数 / 清空可见区
- 设备级操作：开始/停止采集、清设备缓冲（`logcat -c`）、导出 txt（过滤后缓冲快照）
- 级别着色、关键字高亮、崩溃/ANR 信号徽章、堆栈折叠
- 快捷键：Space 暂停 / Ctrl+L 清空 / Ctrl+F 聚焦检索 / Ctrl+T 新建会话 / Ctrl+W 关会话 / Ctrl+Tab 切换
- 单设备（全局焦点）；掉线/切换停采并清共享缓冲（防串设备）

**下一期：** Tab Group 分屏（左右/上下/合并）；轻量检索令牌 `tag:` / `-tag:`（仍非完整 DSL）

**明确不做：** 正则框、完整查询 DSL、多缓冲订阅（main/crash/radio）、多设备并行采集、撕出独立窗口（远期按需）

### 5.4 投屏显示

- **仅 Planned 占位**，本期不实现

## 6. 非功能需求

| 项 | 要求 |
|----|------|
| 性能 | 工控机可用；日志 UI 批量节流 + 虚拟化；启动 < 1.5s（冷启，含 adb 解压）；设备扫描 < 2s |
| 安全 | 不写系统目录/注册表；文件删除限安全根（core 侧校验）；IPC 参数校验在 core |
| 可测 | 领域/解析/会话/判定可单测（cargo test）；组件库可单测（Vitest）；E2E（tauri-driver） |
| 语言 | UI 中文；组件库支持 token 级主题（默认浅色，预留深色） |
| 轻量 | 安装包 ≤ 12 MB；不背运行时（见 G1） |

## 7. 技术选型（v6）

| 层 | 技术 |
|----|------|
| 核心逻辑 | **Rust**（tokio 异步；Cargo workspace：yovo-domain / yovo-adb / yovo-logsrv / yovo-files / yovo-protocol） |

| 测试 | cargo test / Vitest / tauri-driver E2E / 冒烟脚本 |

## 8. 已确认决策（ADR-v6 摘要，全文见架构文档 §12）

| # | 决策 | 结论 |
|---|------|------|
| ADR-v6-002 | 语言栈 | Rust（core）+ TypeScript（UI）；否决纯 Rust 原生 GUI（Slint/egui 中文 IME 缺陷） |
| ADR-v6-003 | UI 载体 | Tauri 2 + WebView2（体积/IME/生态唯一可行交集） |
| ADR-v6-005 | core 边界 | core 零 Tauri 依赖，可独立测试/未来服务化 |
| ADR-v6-006 | 会话与过滤 | 消费端过滤（UI 会话 store）；core 仅采集 + 环形缓冲 + 进程索引 |
| ADR-v6-007 | IPC | 批量协议（100–200ms 聚合，单批上限 1000 行 / 512KB；禁逐行） |
| ADR-v6-008 | ADB | sidecar 官方 adb.exe；不重实现协议 |
| ADR-v6-009 | 成败判定 | 领域层（core）；客户端不判定 |
| ADR-v6-011 | 组件库 | 第一公民；token 单源；lint 禁硬编码 |

## 9. 约束

- OS：Windows 10/11 x64
- WebView2：Evergreen 引导安装（默认）；离线产线镜像一次性预置 Evergreen 或安装包带 offlineInstaller；fixedRuntime（~150 MB）仅作极端离线兜底
- 无管理员权限；数据在 LocalAppData
- 设备通常 USB ADB 连接；产线可能无外网
- 单进程单安装包；模块静态组合（不引入插件热加载）
