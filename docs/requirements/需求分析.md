## 4. 平台能力

### 4.1 工作台壳（Shell）

- 左侧：**设备栏**（型号/序列号/在线状态，可折叠）+ **模块导航**
- 右侧：**单一内容区**（当前模块主视图）
- 底部：**状态栏**（后台任务登记 + 设备状态 + 版本号）
- 导航项来自 `apps/shell` 静态 `registerModule`；`screen-mirror` 为投屏显示（`singleRequired`）
- 设置：导航进入右侧面板（非弹窗）

### 4.2 设备管理

- `adb devices -l` 扫描；显示 device / unauthorized / offline
- 手动刷新 + 启动预热扫描一次 + 可选自动刷新（设置项 `devices_auto_refresh`，秒，默认 0=关）
- **设备目录**与**选择会话**分离：全局焦点 `focusSerial` + 每模块选择作用域
- **运行时状态**（夜览/电量/SDK/亮屏）由 core `DeviceStatusHub` 统一采样，禁止模块自轮询；与目录分流见 ADR-v6-025
- 终端：`MultiOptional`（勾选 ∩ 在线并行，空则回退焦点，禁止默认全在线广播）；文件/日志/投屏：`SingleRequired`（跟在线焦点；日志多窗口绑不同设备是会话模型，新窗口跟焦点）
- 焦点切换：日志分析**不停**其他设备流；某设备掉线：只停该 serial 的采集，已画出的日志行保留

### 4.3 ADB 工具链（sidecar）

- 打包：官方 adb.exe + AdbWinApi.dll + AdbWinUsbApi.dll 作为 **Tauri sidecar** 随安装包分发，运行时解压到 `DataRoot/tools/adb/`；官方 `scrcpy-server` 4.1 同放 `tools/`
- 解析顺序：用户设置（`adb_path`）→ 应用旁 `tools/` → 内置解压
- 进程能力：短命令 / 流式 / 长驻（投屏 `app_process`）
- 明确**不重实现 ADB 协议**（Rust crate 生态不成熟，ADR-v6-008）
- ADB 路径设置**立即生效**；数据目录**重启生效**（启动冻结快照）

### 4.4 应用日志 vs 设备日志（严格分离）

| 类型 | 用途 | 落盘 |
|------|------|------|
| 应用日志 | 应用/模块操作日志（内存环形 + UI 展示） | 默认不落盘；崩溃 panic 日志单独写 `logs/` |
| 日志分析模块 | 设备 `logcat`（core 环形缓冲） | 仅按用户操作导出 txt |

### 4.5 设置（必要项）

| 键 | Scope | 生效 | 默认 | 说明 |
|----|-------|------|------|------|
| `adb_path` | app | 立即 | 空 | 空 = 自动解析 |
| `data_root` | app | 重启 | `%LOCALAPPDATA%\YohuAdbTools\data` | 数据目录 |
| `devices_auto_refresh` | app | 重启 | 0（关） | 自动刷新间隔秒数 |
| `buffer_capacity` | log-analyzer | 窗口立即裁剪；采集环下次启动 | 10000 | 设备共享环形缓冲 / UI 镜像 / 可见区同一上限 |
| `clear_device_on_start` | log-analyzer | 下次采集 | true | 开始前 `adb logcat -c` |
| `log_display_columns` | log-analyzer | 立即 | 全开（ts/uid/pid/tid/level/tag） | 日志清单显示哪些元数据列；消息列始终显示 |
| `theme` | app | 立即 | system | 主题（system/light/dark；默认跟随系统，组件库 token 层支持） |
| `density` | app | 立即 | comfortable | 界面密度（comfortable=鸿蒙 PC 默认；compact=产线收敛；缺字段回落 comfortable） |

设置文件根固定：`%LOCALAPPDATA%\YohuAdbTools\settings\`（不随数据目录迁移）。

## 5. 功能模块需求

### 5.1 ADB 命令终端

- 预设命令库 / 命令组；分类 = 标签（纯派生）
- 占位符 `{0}` `{1}` + 输入提示；校验名称/占位符/正则
- 多设备并行；组内顺序、延时、失败中断（编排在 core 领域层，可单测）
- 成功判定：**失败正则 → 成功正则 → 退出码**（判定在 core 领域层，客户端不判定）
- 管理窗口：深拷贝编辑、保存全量提交、取消零污染
- 数据：`DataRoot/modules/adb-terminal/config/library.json`；损坏或 schema 不匹配时备份为 `.corrupt-<ts>` 后写入默认库
- 结果：结构化展示于模块日志区，测试结果不落盘

### 5.2 文件管理

- 浏览目录（ls 解析，范围限于安全根 `/sdcard`、`/storage`）；上传/下载（进度 + 可取消）；删除/新建目录/新建空文件
- 危险删除：安全根**真子路径**（禁止对 `/sdcard`、`/storage` 本身动手）+ 用户确认；**core 侧强制校验**（不信任 UI 传来的路径）
- 路径规范化，拒绝 `..` 穿越
- 后台任务登记传输

### 5.3 日志分析（基线能力）

**基线（第一期交付即含）：**

- 流式 `adb logcat -v threadtime`（**每设备一路**）；设备级共享环形缓冲；多设备可并行采集
- **多窗口 Tab（= LogSession）**：默认 **System**（Scope=all）；按 **包名 / PID** 再开窗口；进程索引（`ps` 周期刷新）+ 包名 PID 自动重绑（含历史 PID 集）
- AS 风格过滤栏：级别（含以上）/ 包名（含子进程开关）/ 精确 PID / Tag / 关键字检索；**无正则框**
- 每窗口独立：设备、启停、暂停（冻 UI 缓冲继续）/ 自动滚底 / 信号计数 / 清空可见区；新建/复制空且停、不重放共享环；**点开始**按本窗口过滤从当前环补齐（包名窗口先绑 PID），再跟新行
- 当前窗口开始/停止：该设备上 0→1 个窗口在采才 `log.capture.start`，1→0 才 stop；清设备缓冲（`logcat -c`）、导出 txt（过滤后缓冲快照）
- 级别着色、关键字高亮、崩溃/ANR 信号徽章、堆栈折叠
- 快捷键：Space 暂停 / Ctrl+L 清空 / Ctrl+F 聚焦检索 / Ctrl+T 新建窗口 / Ctrl+W 关窗口 / Ctrl+Tab 切换
- 左侧焦点只作新建窗口默认设备；切焦点不停其他设备流；掉线只停该 serial 的采集，已画出的日志行保留

**下一期：** Tab Group 分屏（左右/上下/合并）；轻量检索令牌 `tag:` / `-tag:`（仍非完整 DSL）

**明确不做：** 正则框、完整查询 DSL、多缓冲订阅（main/crash/radio）、每窗口再开 `adb logcat`、撕出独立 OS 窗口（远期按需）

### 5.4 投屏显示

- 选择模式 `singleRequired`；页眉展示选中设备名
- 开始/停止：每设备一路；任务中心登记；退出 3s 杀 adb 进程树
- 默认打开控制通道（点按/滑动、Home/返回/多任务/电源/音量、息屏保持投屏）；页眉「仅显示」可关控制。无音频（`audio=false`）。
- 画面嵌 `YoPanel`，等比适应容器（与编码器 `max_size` 不是同一件事）；锐度由壳内 D3D11 YUV 表面负责（ADR-v6-024）
- 投屏协议 USB / 无线（`max_size` / 码率 / 帧率上限），下次启动生效；USB 默认原分辨率 + HEVC；`tcp:` 连接默认 ADB forward。实测 fps 在状态栏右下角（与编码器上限分开）
- 截图 PNG（壳内从 last 纹理导出 + 本机保存对话框）；面板内全屏；暂停呈现
- 状态：未选择 / 未开始 / 启动中 / 直播 / 失败（server 输出）/ 掉线
- sidecar：`tools/scrcpy-server`（`scripts/setup-scrcpy-server.ps1`，版本钉死 4.1）；画面由系统 Media Foundation 进程内解码（无 ffmpeg sidecar）

**明确不做（本期）：** 音频、录像封装、多设备同时投屏、剪贴板/HID/摄像头/虚拟屏/OTG、独立 scrcpy 主窗、拉起 `scrcpy.exe`

## 6. 非功能需求

| 项 | 要求 |
|----|------|
| 性能 | 工控机可用；日志 UI 批量节流 + 虚拟化；启动 < 1.5s（冷启，含 adb 解压）；设备扫描 < 2s |
| 安全 | 不写系统目录/注册表；文件删除限安全根（core 侧校验）；IPC 参数校验在 core |
| 可测 | 领域/解析/会话/判定可单测（cargo test）；组件库可单测（Vitest）；E2E（tauri-driver） |
| 语言 | UI 中文；组件库支持 token 级主题（默认跟随系统，可手动浅/深） |
| 轻量 | 复用系统 WebView2、不背运行时；安装包大小不作硬门槛（见 G1） |

## 8. 已确认决策（ADR-v6 摘要，全文见架构文档 §12）

| # | 决策 | 结论 |
|---|------|------|
| ADR-v6-002 | 语言栈 | Rust（core）+ TypeScript（UI）；否决纯 Rust 原生 GUI（Slint/egui 中文 IME 缺陷） |
| ADR-v6-003 | UI 载体 | Tauri 2 + WebView2（体积/IME/生态唯一可行交集） |
| ADR-v6-005 | core 边界 | core 零 Tauri 依赖，可独立测试/未来服务化 |
| ADR-v6-006 | 会话与过滤 | 消费端过滤（UI 窗口 store）；core 每设备单流 + 环形缓冲 + 进程索引 |
| ADR-v6-007 | IPC | 批量协议（100–200ms 聚合，单批上限 1000 行 / 512KB；禁逐行） |
| ADR-v6-008 | ADB | sidecar 官方 adb.exe；不重实现协议 |
| ADR-v6-009 | 成败判定 | 领域层（core）；客户端不判定 |
| ADR-v6-011 | 组件库 | 第一公民；token 单源；lint 禁硬编码 |

## 9. 约束

- OS：Windows 10/11 x64
- WebView2：Evergreen 引导安装（默认）；离线产线镜像一次性预置 Evergreen 或安装包带 offlineInstaller；fixedRuntime（~150 MB）仅作极端离线兜底
- 无管理员权限；数据在 LocalAppData
- 设备通常 USB ADB 连接；产线可能无外网
- 单进程单安装包；模块静态组合（不引入插件热加载）
