# 产测助手 — 需求分析

## 1. 项目概述

**项目名称：** Yovo-Windows-ADBTools（产测助手）
**目标平台：** Windows（打包为独立 exe）
**核心定位：** 通过 ADB 实现工厂产测功能的轻量化桌面助手，降低产线测试人员对命令行 ADB 的依赖。

---

## 2. 核心需求

### 2.1 内置 ADB 工具

- 应用程序内置 ADB 二进制文件（adb.exe + 相关 DLL）
- 优先使用系统已安装的 ADB（若存在）
- 系统无 ADB 时自动回退至内置 ADB
- 无需用户额外安装 Android SDK / Platform Tools

### 2.2 命令发送机制

| 场景 | 说明 |
|------|------|
| **单条命令** | 用户从预设列表中选择一条 ADB 命令，点击发送 |
| **命令组** | 一组有序命令，依次执行（如：重启 → 等待 → 检查状态） |
| **规则/功能** | 包含条件判断的复合流程（如：若设备在线则执行测试，否则报错提示） |

### 2.3 用户界面

- 简洁、清晰，适配产线操作人员使用
- 设备列表（连接设备选择）
- 命令分类展示（按功能模块分组）
- 执行日志/输出实时显示
- 执行状态指示（成功/失败/进行中）

### 2.4 轻量化

- 单 exe 打包，体积尽量小
- 低资源占用，可在老旧 Windows 产线工控机上运行
- 无需 .NET Framework 以外额外运行时（如无需 Python 等）

---

## 3. 功能模块（初步规划）

### 3.1 设备管理
- 扫描并列出已连接的 ADB 设备
- 显示设备状态（device / unauthorized / offline）
- 自动刷新 / 手动刷新

### 3.2 命令管理
- 预设命令库（可编辑、可扩展）
- 命令分类：系统信息 / 音频测试 / 蓝牙测试 / WiFi 测试 / 传感器测试 / 按键测试
- 支持配置命令参数（如等待时间、重试次数等）

### 3.3 执行引擎
- 单条命令执行
- 命令组顺序执行（serial）
- 规则引擎（条件判断 + 分支执行）
- 超时控制
- 执行日志输出与保存

### 3.4 配置管理
- 命令库可导入/导出（JSON 或 YAML 格式）
- 保存设备预设配置
- 测试结果导出

---

## 4. 技术选型（初步建议）

| 层次 | 技术 | 理由 |
|------|------|------|
| 语言/框架 | **C# / WPF (.NET 8)** | 原生 Windows 体验，现代化 UI 框架 |
| ADB 集成 | 内嵌 adb.exe 到资源文件 | 进程启动方式调用，无需 SDK |
| 打包 | **.NET 自包含单文件发布** | `dotnet publish -p:PublishSingleFile=true`，无需额外工具 |
| 配置存储 | JSON 文件 | 轻量、可读、可编辑，主流规范 |
| 日志 | 文件 + 界面双重输出 | 产线问题追溯需要 |

> 备选：Python + PyInstaller 打包，但体积较大（~30MB+），且需要额外打包 Python 运行时，不推荐。

---

## 5. 已确认决策

| 决策项 | 结论 |
|--------|------|
| UI 框架 | **WPF (.NET 8)** |
| 多设备并行 | **支持**，可多选设备发送命令 |
| MES 对接 | **预留接口**，暂不实现 |
| UI 语言 | **中文** |
| 配置格式 | **JSON**（主流规范） |
| 厂商自定义命令 | **后续扩展**，预留扩展机制 |

## 6. 约束条件

- 目标 OS：Windows 10 / 11（x64），向下兼容 Windows 7（需安装 .NET 8 运行时）
- 运行时：.NET 8（自包含发布时无需预装运行时）
- 产线工控机可能无管理员权限，注意不要写注册表或系统目录
- 产测设备和 PC 之间通过 USB 连接
